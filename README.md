# 轻量气泡 · 头像＋表情包库（SillyTavern）

这是 SillyTavern 浏览器扩展；与 `extras/` 内世界书和正则配套使用。保留微信气泡样式及此前头像选择；新增可上传的表情包库，包括 GIF 动图。

## 一、通过 GitHub URL 安装

仓库**根目录**必须包含 `manifest.json`、`index.js`、`style.css`。在酒馆「扩展 → 安装扩展」直接填此仓库的完整 URL，例如 `https://github.com/你的用户名/你的仓库名`，即可安装。请勿填本 ZIP 的下载链接。该仓库尚未发布，发布前没有可安装的真实 URL。

## 二、首次启用

1. 在酒馆世界书导入 `extras/轻量气泡-头像表情包联动.json`，停用旧版轻量气泡世界书同名条目，避免冲突。
2. 在酒馆正则导入 `extras/仿微信气泡-头像表情包联动.json`，停用旧的仿微信气泡正则，避免重复套用。
3. 安装并启用本扩展，刷新酒馆。点击气泡头像打开管理面板；若气泡尚未出现，可从扩展设置打开。

升级到这一版会保留此前手动添加的图库项目与已有头像选择；如想切换到新的角色默认头像，打开面板点选。

## 四、表情包

进入「表情包」页 → 「+ 添加表情包」：

- 手机本地图片：PNG、JPG、WebP、GIF；**GIF 保留动图**，不重新编码。单文件最多 10 MB。
- URL：完整 `https://...` 链接，也支持 Catbox 图片短文件名 `q6bahb.jpg`。
- 给每张图写名称、描述（例如「撒娇时用，白色小狗摇尾巴」）；扩展把这些信息提供给 AI。
- AI 在线上剧情里可发送 `<L_EMJ>大菠萝|KbcQEW7.jpg|STK:实际ID</L_EMJ>`；原来的 Catbox 文件名用法也继续支持。**必须使用图库存在的ID**。
- 点击表情包可以查看/复制对应的 STK 代码。删除后旧消息中的表情可能无法显示。

## 五、AI读取机制与数据安全

世界书中的 `{{avatarLibrary}}` 由扩展实时展开头像、表情包索引和当前头像选择。只有当世界书条目被激活时才会进提示词，且只能读**名称/描述/ID**；AI 无法直接看到手机图片的像素内容。

手机本地照片保存在你当前浏览器的 IndexedDB 中，不上传图床，也不会自动同步其他设备。换浏览器、清除网站数据可能丢失，务必保留原图。**同一台手机浏览器可以使用，URL素材更方便跨设备。**

扩展安装仓库 URL 与图床 URL 不一样：前者安装功能代码；后者用于显示图片。本地图片没有外网 URL，扩展通过本机数据库在聊天界面显示。

## 六、技术说明

- 与旧版头像扩展共用 `light_bubble_avatar_library_v1` 键，升级不会主动清空已有头像配置。
- 此版已做 JSON 结构和 JavaScript 静态语法检查；未在用户的酒馆真实环境里跑全流程，实际兼容性仍待验证。
- 宏注册取决于 SillyTavern 版本；若 `{{avatarLibrary}}` 未展开，AI 无法自动引用新表情包，页面手动上传仍可使用。
