# 轻量气泡 · 头像与表情包库 / 1.2.5

- 原作：薄叶（轻量气泡）
- 基于原作二次修改：yspyan；功能扩展由 ChatGPT 协助编写。

## 这版解决的问题

1. **原世界书表情包现在直接显示在图库**：以用户提供的完整世界书为准，预装 223 个 Catbox 表情包（包含重名但文件不同的项目）。不必重新上传。支持名称 / 文件名搜索，默认展示前 36 张，点「显示更多」继续展开，避免在手机上一次加载 200 多张。
2. **自定义图库与世界书预设分开**：世界书预设显示「世界书预设」，不能在扩展里误删；自己后来上传的表情包仍可删除。旧头像/本地图、已选头像不清空。
3. **新增内容自动提供给 AI**：每次生成前尝试用 SillyTavern `setExtensionPrompt` 把新上传的头像及表情包的**名称、描述、实际ID**和当前头像选择加入本轮提示词。**这不是写回世界书文件**，不会改动原世界书，也不需要每加一张就手改世界书。旧 `{{avatarLibrary}}` 宏仍保留作为世界书触发时的备用路径。
4. 原世界书的表情包索引仍由世界书条目提供给 AI；动态注入主要针对**新添加的**素材，避免把世界书 200 多条重复发两遍、浪费 token。

## 安装和验证

只替换 `index.js`、`style.css`、`manifest.json`、`README.md` 即可，不要覆盖你的世界书、正则。酒馆「扩展 → 管理扩展 → 更新」，必要时刷新一次。

保存一张新图片后，在下一次模型生成的「Prompt/提示词」视图中搜索 `轻量气泡 · 动态素材补充` 或 `STK:你的图片ID` 来确认是否真的注入。如果没有找到，说明你使用的酒馆版本未提供或未调用 `setExtensionPrompt`；旧世界书里只有 `{{avatarLibrary}}` 宏激活时才可能让 AI 读到动态索引。**不能凭面板里显示已保存就断定 AI 看到了。**

**设备本地图片只存在当前浏览器，扩展不能自动上传到外网，也不能让 AI 看见图片像素。AI 只读你填写的名称和描述。** 清除浏览器网站数据会有丢失风险。

## 当前已知限制

SillyTavern 的版本和用户主题各不相同；本版进行了浏览器模拟和源码检查，尚未在你的 OPPO 酒馆环境中完成真实验证。原先的自动刷新钩子在这个版本没有改动，其是否有效取决于酒馆更新流程的支持。
