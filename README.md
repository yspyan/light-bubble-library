# 轻量气泡 · 动态素材渲染修复 v1.2.6

原作署名：薄叶（轻量气泡）。二次修改：yspyan；扩展功能代码由 ChatGPT 协助制作。

## 修复了什么

1. 修复消息内头像字段为图库 ID（例如 `avatar_mw925z40_casltd`）时被错误拼成 `https://iili.io/avatar_...` 而出现破图。新的扩展会在图库查找这个真实 ID，并从当前浏览器读取对应图片。
2. 修复自定义表情包 `STK:sticker_xxx` 不被旧正则识别而显示原始标签的问题。新正则同时支持 **旧 Catbox 文件名** 和 **新 STK ID**，通过扩展动态填图。
3. 给每类气泡的头像添加 `data-lb-avatar-ref` 属性用于精确取回标签中的头像 ID，保留原本所有气泡样式。
4. 原有 `> ⤙ <` 等颜文字和 223 个世界书预设表情包的匹配方式没有更改。

## 需要更新什么

- GitHub 仓库根目录：替换 `index.js` 和 `manifest.json`。`style.css` 与上版相同，无需替换。
- 酒馆正则：**必须导入** `轻量气泡_兼容动态图片的正则.json`，并禁用/删除旧的整套「仿微信气泡」正则，避免先被旧表达式处理。旧世界书不必更换。
- 进入酒馆扩展管理点击「更新」，刷新酒馆页面，然后试读原来的聊天记录，已保存的本地图片应能显示。

注意：如果聊天记录用了 `STK:xxx`，但上传该图的浏览器已清除数据或换了设备，则无法凭 ID 恢复图片。AI 看到的是图库名称、描述和 ID，并非图片内容。测试必须在保存了对应图片的同一浏览器进行。

本包测试包含正则匹配与真实浏览器 DOM 回填的本地自动化，但尚未经用户的酒馆环境实测。
